
# Gel Photometric Forensics

A CPU-based classical image processing framework for detecting localized photometric manipulation in scientific gel and western blot images.

## Objective

Develop an interpretable system to distinguish legitimate global photometric adjustments from suspicious localized brightness, contrast, gamma, and tonal edits.

## Tech Stack

- Python
- OpenCV
- NumPy
- SciPy
- scikit-image
- Matplotlib
